# marcosba.github.io

Este repositorio aloja el blog personal de Marcos en GitHub Pages, con una estética oscura, minimalista y de una sola columna.

La idea principal es mostrar una presencia web personal basada en sus proyectos de GitHub: automatización, IA, prototipos, documentación técnica y experimentos software.

## Estado

- Sitio estático listo para GitHub Pages
- Diseño de una sola columna
- Tema oscuro y minimalista
- Contenido adaptado a los repositorios públicos de marcosba

## Publicación

GitHub Pages sirve automáticamente el archivo `index.html` desde la raíz del repositorio cuando está activo para `marcosba.github.io`.
